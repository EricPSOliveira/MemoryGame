## MemoryGame 

## Sobre

Projeto dedicado principalmente para aprendizados relacionados a programação orientada a objetos e a pratica de tecnologias internas do Java. Esse é um teste pratico de variadas funções presentes na linguagem e em fundamentos da programação, projeto visa entender o funcionamento de listas e geração de padrões randômicos por meio de um objeto Java. 

## Funcionalidades

 - Sistema de Aleatorização de padrões para funcionamento do jogo.
 - Uso de lista e verificações para conectar imagens iguais.
   
## Tecnologias

 - Java
 - JFrame
